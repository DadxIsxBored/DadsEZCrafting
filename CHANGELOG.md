# Changelog

## 0.1.0

- Added native crafting-list search.
- Added item-type filters with All selected by default.
- Added biome progression-tier filters from Meadows through Deep North.
- Added native, alphabetical, Health, Stamina, and Eitr sorting.
- Added a compact three-row toolbar confined to the existing recipe-list column.
- Added configurable tier prefab hints for modded recipes and future content.
- Expanded the default biome mappings with Valheim Fandom Wiki item IDs and Deep North progression materials.
- Built against Valheim 1.0.12 and BepInEx 5.4.23.5.
