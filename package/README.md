# DadsEZCrafting

DadsEZCrafting adds compact native-styled search, category, progression-tier, and ordering controls to Valheim 1.0.12 crafting-station menus.

## Default state

- Type: All
- Tier: All Tiers
- Sort: Native

## Item categories

Weapons, Armor, Shields, Ammo / Throwables, Food, Tools, Materials, and Other.

## Progression tiers

Meadows, Black Forest, Swamps, Mountain, Plains, Mistlands, Ashlands, and Deep North.

Food recipes can be ordered by Health, Stamina, or Eitr. Tier classification uses the live recipe output, required materials, and crafting station. Configurable prefab-name hints support modded recipes and future content.

The toolbar remains inside the native recipe-list column and does not replace the crafting details, requirements, upgrade, or craft-button areas.
